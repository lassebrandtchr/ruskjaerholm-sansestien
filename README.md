# Sansestien · Ruskjærholm

Hjemmeside for Sansestien på Ruskjærholm med Lindy Nielsens træskulpturer.

**Live:** https://lassebrandtchr.github.io/ruskjaerholm-sansestien/

## Sådan retter du
- **Tekst på en station:** ret `titel` / `tekst` i `data/stationer.js`. Rækkefølgen i filen = rækkefølgen på stien.
- **Billede på en station:** læg nyt billede i `billeder/stationer/` (lille, vises på stien) og `billeder/original/` (stort, vises når man trykker) med samme filnavn.
- **Velkomst, de 3 stier, Lindy:** ret direkte i `index.html`.
- Gem → commit → push. GitHub Pages opdaterer siden efter ca. 1 minut.

## Senere
Feltet `sti` på hver station er klar til opdelingen i kort (1,1 km) / mellem (2,2 km) / hele (3,4 km).
